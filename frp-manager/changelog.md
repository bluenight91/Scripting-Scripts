## 本次更新（2.0.0）

全新界面设计，与 Surge Panel 共用同一套视觉语言。

- 主页：顶部概览卡片显示在线数量与 frpc / frps 条目数，轻点重新检测；服务器以图标卡片展示，状态用胶囊标识，长按或左滑可编辑 / 删除
- 添加 / 编辑服务器改为弹出表单，带「取消」与「保存」，类型用卡片选择
- frpc：代理 / 运行中 / 异常三项指标，按类型芯片筛选代理；配置文件改为等宽编辑器并显示同步状态；Store 新建代理改为弹出表单
- frps：渐变主卡片显示总流入 / 流出、客户端、连接与代理数；代理类型芯片带数量；代理详情以指标块展示今日与累计流量
- 客户端列表：在线 / 离线 / 全部芯片筛选，版本、系统与用户以标签显示
