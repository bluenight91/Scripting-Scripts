## 本次更新（1.1.0）

- 脚本与首页标题改为英文名 Cloudflare Observability
- 小组件项目可以取消：再次左滑 / 长按、项目详情或设置页都可取消，未选定时小组件显示账户总用量（Workers / Pages 分布、错误数、用量最高的项目）；小组件参数填 `account` 也可固定显示账户
- 配色改用 Cloudflare 标志的黄橙色，去掉主卡片后方的蓝色光晕
- 项目详情的四个指标块大小统一

## 1.0.0

首个版本。

- 概览：账户限额主卡片（Workers Free 按 UTC 日 10 万次请求；Workers Paid 按账单周期 1,000 万次请求与 3,000 万 CPU 毫秒，并估算超额费用），Worker 与 Pages 项目列表显示本周期请求数
- 项目详情：1 小时 / 24 小时 / 7 天 / 本周期切换；请求、错误率、子请求、CPU P50 / P99（Free 对比 10 ms 上限）、Wall time P99、调用状态分布与请求柱状图
- 日志：Workers Observability 最近事件、只看错误、全文搜索，按路径 / 状态码 / 结果 / 国家分组的 Top 列表，点按查看事件详情
- 设置：用户 API 令牌（存 Keychain）、Account ID 自动识别、套餐与账单周期日、一键检查令牌权限
- 小组件：小 / 中 / 大尺寸与锁屏圆形 / 矩形，显示选定项目的限额使用，每 15 分钟刷新；小组件参数可填项目名覆盖
